# Project Finder · 本地工作经验

版本 0.3。通过任务执行、验证和复用，逐步形成适合使用者的本地工作流程。适用于有重复性且能验收的工作，不限于开发；具体任务仍需要相应领域技能与工具。

## 三层结构

- 通用机制：规定何时记、如何找、怎样验证与更新。
- 场景流程：从真实任务中形成输入、步骤、分支和验收。
- 本地经验：保留任务证据、限制、约定和已验证做法。

查看 [完整方案](ARCHITECTURE.md) 与 [Skill 入口](SKILL.md)。

## 使用

将整个 project-finder 文件夹放到宿主支持的 Skill 目录，由宿主加载 SKILL.md。避免同时启用同名旧版入口。本包不会自动替换已安装版本。

示例请求：

- “用 project-finder 完成这次月报，核对结果后沉淀值得复用的流程。”
- “按上次流程处理本月资料，先检查输入和口径有没有变化。”
- “找找以前如何解决重复提交问题，这次只查询。”
- “将这个流程失效的原因记录下来，修订适用范围。”

默认保存到目标工作目录的 .project-finder/；空库也能执行任务。只有参与任务且能取得结果时才积累经验，不后台监听其他会话，不自动推断个人习惯。

## v0.3 升级

新增 run、lesson、workflow 三种 v2 记录。兼容已有 v1 开发记录；需要新类型时将库配置版本升级到 2，不批量重写旧档案。v0.2 检查工具不能维护 v2 库。

只读检查和索引预览需要 Python 3.9+ 与 PyYAML；没有这些依赖时可按文档人工检查。工具不验证事实，也不自动把候选提升为可用。

## 发布范围

此包仅含规则、模板和维护工具，不含原私有项目档案、SDK 或业务骨架。用户知识库与规则包分开升级。公开许可证与发布平台由维护者确定，本仓库暂未指定开源许可证。

格式和工具检查不代表实际复用效果已经验证。建议先用原来的开发场景和一个非开发重复任务进行真实试用。
